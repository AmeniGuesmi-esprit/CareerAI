# Grille d'évaluation

## Échelle de notation

### Échelle de 0 à 10
- **Catégorie** : evaluation
- **Tags** : notation, score, evaluation
- **Contenu** : 0-2 hors sujet ou inexact ; 3-4 partiel, des notions sans structure ; 5-6 correct, il manque la précision ou un exemple ; 7-8 solide, précis et structuré ; 9-10 complet, précis, avec exemple chiffré et recul critique.

## Critères

### Exactitude technique (poids 40 %)
- **Catégorie** : evaluation
- **Tags** : exactitude, technique, precision
- **Contenu** : les notions sont correctes, les termes employés à bon escient, aucune affirmation fausse. Une erreur grave plafonne la note à 4.

### Couverture des points attendus (poids 25 %)
- **Catégorie** : evaluation
- **Tags** : couverture, points attendus
- **Contenu** : la réponse couvre les points attendus de la question. Compter les points traités, pas le volume de texte.

### Structure et clarté (poids 15 %)
- **Catégorie** : evaluation
- **Tags** : structure, clarte, communication
- **Contenu** : une idée par phrase, un plan lisible (contexte, solution, limites), une réponse qui va à l'essentiel en deux minutes.

### Exemple et preuve (poids 20 %)
- **Catégorie** : evaluation
- **Tags** : exemple, experience, preuve
- **Contenu** : la réponse s'appuie sur une expérience concrète ou un cas d'usage. Pour une question comportementale, la méthode STAR doit être visible.

## Signaux d'alerte

### Drapeaux rouges
- **Catégorie** : evaluation
- **Tags** : alerte, pieges, drapeaux rouges
- **Contenu** : affirmer sans justifier, éviter la question, critiquer un ancien employeur ou collègue, s'attribuer le travail d'une équipe, inventer une expérience. Chacun doit être signalé dans les lacunes.

## Contrôle STAR

### Vérification pour les questions comportementales
- **Catégorie** : evaluation
- **Tags** : star, comportemental, verification
- **Contenu** : vérifier la présence des quatre temps. Il manque la Tâche : la responsabilité n'est pas claire. Il manque l'Action : la réponse décrit l'équipe, pas le candidat. Il manque le Résultat : aucun effet ni enseignement. Signaler chaque temps absent dans les lacunes.

## Amélioration

### Réponse améliorée
- **Catégorie** : evaluation
- **Tags** : amelioration, reponse modele
- **Contenu** : la réponse améliorée reprend les points forts, comble les lacunes principales et reste dans la longueur d'une réponse orale (150 mots maximum).
