# Questions comportementales

## Travail en équipe

### Parlez-moi d'un conflit avec un membre de votre équipe
- **Catégorie** : comportementale
- **Niveau** : junior
- **Tags** : equipe, conflit, communication
- **Intention** : évaluer la gestion des désaccords et la capacité à rester constructif.
- **Points attendus** : situation précise ; écoute de l'autre point de vue ; action concrète pour résoudre ; résultat mesurable ; leçon retenue.
- **Réponse modèle (plan)** : situation du conflit, ce que vous avez fait pour comprendre l'autre, décision prise, résultat pour l'équipe.
- **Pièges** : désigner un coupable ; rester flou sur votre rôle.

### Décrivez une situation où vous avez aidé un coéquipier
- **Catégorie** : comportementale
- **Niveau** : junior
- **Tags** : equipe, entraide, collaboration
- **Intention** : mesurer l'esprit d'équipe.
- **Points attendus** : besoin identifié ; aide apportée sans prendre le travail de l'autre ; impact.
- **Réponse modèle (plan)** : contexte, aide proposée, résultat collectif.
- **Pièges** : aide qui se résume à faire le travail à sa place.

### Un désaccord technique avec un collègue senior
- **Catégorie** : comportementale
- **Niveau** : confirme
- **Tags** : equipe, desaccord, technique, communication
- **Intention** : évaluer l'argumentation et l'humilité technique.
- **Points attendus** : arguments techniques ; prototype ou mesure pour trancher ; décision acceptée.
- **Réponse modèle (plan)** : contexte, position initiale, preuve apportée, décision finale.
- **Pièges** : avoir raison à tout prix.

### Travailler avec une personne difficile
- **Catégorie** : comportementale
- **Niveau** : confirme
- **Tags** : equipe, communication, relation
- **Intention** : tester l'adaptation au comportement d'autrui.
- **Points attendus** : compréhension des besoins ; ajustement de sa communication ; cadre clair.
- **Réponse modèle (plan)** : situation, observation, changement de méthode, résultat.
- **Pièges** : critiquer la personne plutôt que le comportement.

## Gestion des priorités et des délais

### Gérer plusieurs échéances en même temps
- **Catégorie** : comportementale
- **Niveau** : junior
- **Tags** : priorites, delais, organisation
- **Intention** : évaluer l'organisation personnelle.
- **Points attendus** : hiérarchisation par impact ; communication sur les arbitrages ; respect des délais clés.
- **Réponse modèle (plan)** : charge, critères de priorité, communication, résultat.
- **Pièges** : tout faire en même temps sans prévenir.

### Respecter un délai très serré
- **Catégorie** : comportementale
- **Niveau** : confirme
- **Tags** : delais, pression, planification
- **Intention** : observer la réaction sous pression.
- **Points attendus** : découpage du travail ; périmètre minimal livrable ; suivi régulier.
- **Réponse modèle (plan)** : contrainte, plan de découpage, livraison, enseignement.
- **Pièges** : promettre sans évaluer la faisabilité.

### Dire non ou négocier une demande
- **Catégorie** : comportementale
- **Niveau** : confirme
- **Tags** : priorites, negociation, communication
- **Intention** : évaluer la capacité à poser des limites.
- **Points attendus** : explication de l'impact ; alternative proposée ; accord trouvé.
- **Réponse modèle (plan)** : demande, impact chiffré, proposition, issue.
- **Pièges** : refuser sans proposer d'alternative.

## Échecs, erreurs et apprentissage

### Racontez une erreur que vous avez commise
- **Catégorie** : comportementale
- **Niveau** : junior
- **Tags** : erreur, responsabilite, apprentissage
- **Intention** : vérifier l'honnêteté et la capacité à corriger.
- **Points attendus** : reconnaissance claire ; correction rapide ; mesure pour éviter la récidive.
- **Réponse modèle (plan)** : erreur, impact, correction, mesure préventive.
- **Pièges** : minimiser l'erreur ou accuser le contexte.

### Un projet qui a échoué
- **Catégorie** : comportementale
- **Niveau** : confirme
- **Tags** : echec, retrospective, apprentissage
- **Intention** : évaluer le recul sur un échec.
- **Points attendus** : causes analysées ; ce qui était de votre ressort ; changements appliqués ensuite.
- **Réponse modèle (plan)** : projet, causes, responsabilité, actions suivantes.
- **Pièges** : rejeter la faute sur l'équipe.

### Recevoir un feedback difficile
- **Catégorie** : comportementale
- **Niveau** : junior
- **Tags** : feedback, progression, communication
- **Intention** : tester l'ouverture à la critique.
- **Points attendus** : écoute ; demande de précisions ; plan d'amélioration suivi.
- **Réponse modèle (plan)** : feedback reçu, réaction, actions, évolution constatée.
- **Pièges** : se justifier sans écouter.

### Apprendre une technologie rapidement
- **Catégorie** : comportementale
- **Niveau** : junior
- **Tags** : apprentissage, autonomie, technologie
- **Intention** : évaluer la capacité d'adaptation.
- **Points attendus** : méthode d'apprentissage ; projet d'application ; résultat livré.
- **Réponse modèle (plan)** : besoin, méthode, mise en pratique, résultat.
- **Pièges** : citer une formation sans application concrète.

## Initiative et leadership

### Une initiative que vous avez prise
- **Catégorie** : comportementale
- **Niveau** : confirme
- **Tags** : initiative, amelioration, autonomie
- **Intention** : repérer la proactivité.
- **Points attendus** : problème repéré ; action sans demande explicite ; impact mesuré.
- **Réponse modèle (plan)** : constat, proposition, mise en œuvre, gain.
- **Pièges** : initiative sans résultat chiffré.

### Diriger un groupe sans autorité formelle
- **Catégorie** : comportementale
- **Niveau** : senior
- **Tags** : leadership, influence, coordination
- **Intention** : évaluer l'influence et la coordination.
- **Points attendus** : objectif partagé ; répartition claire ; suivi et ajustements.
- **Réponse modèle (plan)** : contexte, méthode de coordination, difficultés, résultat.
- **Pièges** : parler au nom de l'équipe sans l'avoir consultée.

### Transmettre des connaissances à un collègue
- **Catégorie** : comportementale
- **Niveau** : confirme
- **Tags** : mentorat, transmission, equipe
- **Intention** : évaluer la capacité à faire monter les autres en compétence.
- **Points attendus** : besoin évalué ; méthode pédagogique ; autonomie obtenue.
- **Réponse modèle (plan)** : besoin, méthode, suivi, autonomie atteinte.
- **Pièges** : donner la solution sans expliquer.

### Prendre une décision difficile
- **Catégorie** : comportementale
- **Niveau** : senior
- **Tags** : decision, responsabilite, arbitrage
- **Intention** : observer le raisonnement en situation d'incertitude.
- **Points attendus** : options comparées ; critères explicites ; décision assumée et suivie.
- **Réponse modèle (plan)** : contexte, options, critères, décision, résultat.
- **Pièges** : décision sans critère ni communication.

- **Réponse modèle (plan)** : plainte, écoute, action corrective, satisfaction.

### Présenter un projet à une audience
- **Catégorie** : comportementale
- **Niveau** : confirme
- **Tags** : presentation, communication
- **Intention** : évaluer la capacité à convaincre.

- **Réponse modèle (plan)** : objectif de la présentation, structure, questions, suite donnée.

## Motivation et projection

### Pourquoi ce poste et pourquoi notre entreprise
- **Catégorie** : comportementale
- **Niveau** : junior
- **Tags** : motivation, entreprise, projet professionnel
- **Intention** : vérifier l'intérêt réel et la préparation.
- **Points attendus** : connaissance de l'entreprise ; lien avec ses projets ; cohérence avec le parcours.
- **Réponse modèle (plan)** : trois raisons concrètes liées à l'entreprise et au poste.
- **Pièges** : réponse générique applicable à toute entreprise.

### Quelles sont vos forces et vos axes d'amélioration
- **Catégorie** : comportementale
- **Niveau** : junior
- **Tags** : autoevaluation, progression
- **Intention** : mesurer la lucidité.
- **Points attendus** : deux forces illustrées ; un axe réel avec un plan concret.
- **Réponse modèle (plan)** : force avec exemple, axe avec action en cours.
- **Pièges** : faiblesse déguisée en qualité.

### Où vous voyez-vous dans trois ans
- **Catégorie** : comportementale
- **Niveau** : junior
- **Tags** : projet professionnel, evolution
- **Intention** : vérifier l'ambition et la cohérence.
- **Points attendus** : objectifs réalistes ; progression vers des responsabilités ; lien avec le poste.
- **Réponse modèle (plan)** : objectif technique, objectif de responsabilité, rôle de l'entreprise.
- **Pièges** : objectif sans lien avec le poste.

### Votre plus grande réussite professionnelle
- **Catégorie** : comportementale
- **Niveau** : confirme
- **Tags** : reussite, impact, resultats
- **Intention** : mesurer l'impact et la capacité à se valoriser.
- **Points attendus** : contexte ; contribution personnelle ; résultat chiffré.
- **Réponse modèle (plan)** : contexte, votre rôle, résultat mesuré, ce que vous en retenez.
- **Pièges** : mettre en avant le résultat de l'équipe sans préciser votre part.

### Une situation où vous avez dû vous adapter au changement
- **Catégorie** : comportementale
- **Niveau** : confirme
- **Tags** : adaptation, changement, flexibilite
- **Intention** : évaluer la flexibilité.
- **Points attendus** : changement décrit ; réaction positive ; adaptation concrète.
- **Réponse modèle (plan)** : changement, résistance éventuelle, adaptation, bénéfice.
- **Pièges** : se plaindre du changement sans agir.
